### 复审方法要点（可复用）
- Supabase Management SQL 端点支持 `begin; ... select ...; rollback;` 且**返回最后一条 SELECT 的行** → 是零副作用探针的关键手法。
- **幂等/并发类探针必须 `commit`**：用 rollback 包裹会连收据一起回滚，导致「同 key 重放未返回 replayed:true」的**假缺陷**。此处踩过坑。
